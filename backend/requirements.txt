# ── Phase 11 security audit: UNRESOLVED transitive vulnerabilities ───────────
# python-jose depends on ecdsa, which depends on pyasn1<0.5.0. That transitively
# locks the project to:
#   pyasn1 0.4.8  - 4 CVEs (PYSEC-2026-2263/3455/3456/3457), fixed in 0.6.4
#   ecdsa  0.19.2 - PYSEC-2026-1325, NO FIXED VERSION AVAILABLE
#
# Pinning pyasn1>=0.6.4 makes dependency resolution impossible - verified.
# The real remedy is migrating JWT handling from python-jose to PyJWT, which
# uses `cryptography` for ECDSA rather than the pure-Python `ecdsa` package.
#
# Risk assessment: ReturnIQ signs JWTs with HS256 (HMAC-SHA256), which does not
# exercise the ECDSA code path at all. Exposure is therefore low in the current
# configuration - but it becomes real the moment anyone switches to an RS/ES
# algorithm. Tracked as the top open item in phase11/security/DEPENDENCY_AUDIT.md.
